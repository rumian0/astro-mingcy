## 关于 Mingcy

Mingcy 是一个使用 Astro 和 React 开发的博客主题，以 [astro-gyoza](https://github.com/lxchapu/astro-gyoza) 为基线深度定制。

它借鉴了 [Shiro](https://github.com/innei/Shiro) 和一些网站的设计，核心理念是：**SPA 级导航体验**、**长文阅读质感**、**构建体积与运行时开销控制**。

- 可以前往 [主题介绍](/2024/01/21/intro/) 了解 Mingcy 的特性与配置方式
- 在 [排版功能指南](/2026/07/16/features/) 中展示了所有 Markdown 与排版增强样式

Mingcy 是开源的，如果你对这个项目感兴趣，欢迎前往 [Github 仓库](https://github.com/rumian0/astro-mingcy) 来提 Issue 或者 PR。
